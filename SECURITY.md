# Security policy

steadybot is in early development. It has not been audited and is not ready for production use.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub instead: open the repository's **Security** tab and choose **Report a vulnerability**. You should get a reply within 7 days.

## What we especially want to hear about

- Data from one user's space becoming visible to another user's bots.
- Secrets reaching model context, traces or logs.
- Content from a web page, email or file making a bot take an unapproved consequential action.
- Escaping a bot's sandboxed computer, or reaching internal network addresses from it.
- Ways to run up model or compute spend beyond a user's quota.
